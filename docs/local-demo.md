# 5-10 minute demo guide

Record the actual dashboard and terminal, with no real prospect/customer data visible. Use the labelled fictional sample workspaces.

| Time | Demonstration |
| --- | --- |
| 0:00-1:00 | Explain the local architecture. Show the tested Git commit, Ollama model, hardware recommendation and zero token charges. |
| 1:00-2:00 | Switch Sentinel/Relay, show their product settings and different ICPs. Explain product isolation. |
| 2:00-4:30 | With Wi-Fi disabled, run a fresh single-prospect pipeline. Show profile, ICP, research, embedding similarity, signals, problem, score and email draft. Use an honest cut or time-lapse if CPU inference exceeds recording time; say so on screen. |
| 4:30-5:30 | Classify a saved reply and show its category, confidence and reason. Show that emails remain drafts. |
| 5:30-6:30 | Inspect/export inference logs with loopback endpoint, source, timestamps, duration and token counts. |
| 6:30-7:30 | Stop the project runtime, queue a task, show actionable waiting status while browsing/editing remains usable, then restart and show recovery. |
| 7:30-9:00 | Show automated test results, audit output, licence/cost documentation and known limitations. |

The recording must show real outputs from the submitted version. This guide is not itself a video deliverable. A physical disconnected state and the final remote repository URL still need to be captured for submission.
